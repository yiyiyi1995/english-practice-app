# Fluent 120

一个无需安装、可离线使用的英语冲刺练习网页。包含阅读、听力、口语、写作、专项题库和 120 分制模拟考试。

## 使用

直接双击 `index.html`，或在本目录执行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

建议使用最新版 Chrome 或 Edge，以获得语音识别支持。听力播放使用浏览器内置语音合成。

## 说明

- 题目为原创内容，题型参考数字化英语能力测试，难度约 B2–C1。
- 模考总分 120，四项各 30 分。
- 写作、口语采用本地启发式规则估分，仅用于训练反馈，不是官方成绩。
